# 微信防撤回插件（macOS）

让对方撤回的消息继续显示在你的聊天记录中。

> **适用版本**：微信 4.1.8（build 36603）  
> **适用系统**：macOS（Apple Silicon，arm64）

---

## 安装

> 安装过程需要在"终端"中运行几条命令，并输入开机密码。全程约 1 分钟。

**第一步：下载插件**

如果你还没有下载，点击页面右上角的绿色 **Code** 按钮 → **Download ZIP**，解压到任意位置（例如桌面）。

**第二步：打开终端**

按 `Command + 空格`，输入"终端"，回车打开。

**第三步：进入插件目录**

把解压后的文件夹拖进终端窗口（会自动填写路径），然后在路径前加上 `cd `，回车。

例如：
```
cd /Users/你的用户名/Desktop/anti-revoke-main
```

**第四步：完全退出微信**

点击顶部菜单栏"微信" → "退出微信"，确保微信完全关闭（不是最小化）。

**第五步：运行安装脚本**

在终端输入以下命令，回车：

```bash
sudo python3 patch_wechat.py --backup
```

系统会提示输入开机密码（输入时不显示，正常），输入后回车。

看到 `Done! Restart WeChat for changes to take effect.` 表示安装成功。

**第六步：重新打开微信**

正常启动微信，防撤回立即生效，无需任何其他设置。

---

## 验证是否生效

安装后，让朋友发一条消息再撤回，如果你这边消息依然可见，即为成功。

---

## 卸载

在终端进入插件目录后，运行：

```bash
sudo python3 patch_wechat.py --restore
```

输入开机密码，完成后重启微信，恢复原版。

---

## 微信更新后怎么办

微信自动更新后插件会失效。重新运行一次安装命令即可：

```bash
sudo python3 patch_wechat.py --backup
```

> **注意**：若微信更新到新的大版本（非 4.1.8），插件可能暂时不兼容，需等待适配。

## 常见问题

**问：安装后我自己撤回消息会怎样？**  
答：他人的撤回全部拦截；你通过手机撤回的消息也会被拦截（消息保留）；你通过 Mac 端点击撤回，按微信原版逻辑执行。

**问：不影响微信正常使用吗？**  
答：防撤回只修改了消息展示逻辑，聊天、发送、收发文件等功能完全不受影响。

**问：提示 "WARNING: This patch is designed for build 36603" 怎么办？**  
答：说明你的微信版本已更新，插件可能不兼容。输入 `n` 取消，等待插件适配新版本。

**问：codesign 报错怎么办？**  
答：手动运行：`sudo codesign --force --deep --sign - /Applications/WeChat.app`

## 工作原理（简述）

本插件通过两层防护拦截撤回：

1. **二进制补丁**：直接修改微信内部"是否为撤回消息"的判断函数，使其始终返回"否"
2. **动态钩子**：运行时替换函数指针，进一步保障兼容性

两层保障确保原始消息不被删除。
